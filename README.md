# Melanoma Therapy Resistance Analysis

This project identifies gene regulatory networks from RNA-seq data (GSE162187 and GSE78220).

## 📊 Project Structure
- `files/`: Python analysis scripts.
- `slurm_scripts/`: HPC submission scripts.
- `data/`: Raw TSV files (Gitignored).
- `setup_data.sh`: Script to fetch data from NCBI GEO.

## 🚀 Quick Start
1. Clone the repo.
2. Run the data setup script:
   ```bash
   bash setup_data.sh
